#Patrones de diseño aplicados
- **Factory Method (creacional):** FabricaAnimal crea Perro, Gato u OtroAnimal sin acoplar el código cliente a las clases concretas.
- **Strategy (comportamiento):** EstrategiaEvaluacion permite cambiar el criterio de evaluación de una solicitud de adopción.
- **Observer (comportamiento):** Animal notifica a sus observadores cuando cambia su estado.
- **Adapter (estructural):** AdaptadorCorreoExterno aísla al sistema de la API del servicio de mensajería.
